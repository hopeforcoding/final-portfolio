# final-portfolio

A personal portfolio website showcasing my work across art, design, and web development. This project blends visual storytelling with interactive front-end development to create a digital space that reflects my creative practice. 

Overview

I used a simple black and white aesthetic to reflect my analogue fine art practice and stark blue and yellow to contrast the digital practice of design and web development. As an attemp to decompartmentalise my practice and thinking, I used these throught my site, with photography to show how I approach my work.

Used

HTML5
CSS3 (Flexbox + Grid)
Vanilla JavaScript
Google Fonts (IBM Plex Mono)
